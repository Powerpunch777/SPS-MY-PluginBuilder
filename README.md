# SPS MY Plugin Builder

SPS is Redon's local-first Desktop workspace for building AI-assisted projects with durable context and control over project sources. **MY Plugin Builder** is a design project for a specialized SPS plugin that helps its owner turn client requirements into reviewed software and delivery packages.

The Builder concept uses an SPS Workspace as its project boundary and explores a Lead/CTO/Worker/QA workflow, requirement-to-design links, reuse research, code work, verification evidence, and controlled handoff. It is a purpose-built solution-building tool, not the SPS platform itself or a public plugin marketplace.
