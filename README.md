# SPS MY Plugin Builder

자체 외주 사업의 고객 요구, 설계, 구현, 검증 및 납품을 관리하는 SPS 플러그인입니다. 공개 플러그인 마켓플레이스나 별도 범용 SaaS를 목표로 하지 않습니다.

현재 저장소는 **설계 보관 및 검토 단계**입니다. Builder 제품 구현, 의존성 설치, 테스트 및 CI 실행은 아직 시작하지 않았습니다. HTML은 실제 Core·Codex·GitHub와 연결되지 않은 UI 시제품입니다.

원본 설계와 실제 구현 상태는 구분합니다. 원본의 구현 지시는 설계 자료이며, 이번 문서 저장을 Builder 또는 Core 개발 재개로 해석하지 않습니다. 기존 Core 개발은 사용자 요청에 따라 중지된 상태입니다.

후속 사용자 지시에 따라 검토한 구성요소의 라이선스 차이는 설계 채택의 차단 사유로 삼지 않습니다. 구성요소의 실제 라이선스와 고지는 그대로 유지하며, 이 저장소 전체에 별도의 라이선스를 임의로 부여하지 않습니다.
