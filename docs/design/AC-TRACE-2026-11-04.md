[기계 판독 추적표](AC-TRACE-2026-11-04.json)는 실제 원문 정의를 읽어 작성했다.
기본 v15 118개, CSAS v0.8 44개, 상담 개정 8개, 문서센터 v1.1 16개, 통합 추가 16개,
최종 검토·승인 추가 14개로 **서로 다른 정의 ID는 216개**다.
원문·소스 해시·행·개정과 후속 정책 적용 관계를 함께 보존한다.
이는 216개의 서로 독립적인 요구사항이나 216개 시험 통과를 뜻하지 않는다.
과거의 162개는 첫 두 문서만 합친 정의 수이며 상담 개정 8개는 별도다.
과거 170개 목록에 AC-DOC-01~16을 추가했으며 기존 정의·원문·증거 상태는 보존했다.
통합 추가 설계의 AC-INT-01~16을 더한 202개에 2026-11-05 사용자 확정 AC-APP-01~14를
추가했다. 기존 원문·증거·인수 상태는 보존하며 새 행도 구현/인수 전에는 NOT_RUN이다.
개정된 통합 설계 사본의 소스 해시·정의 행 번호는 현재 파일에 맞춰 갱신한다.

2026-11-05의 [범용 권한·Host 위임 결정](01_Design/SPS_Builder_Generic_Permissions_And_Host_Delegation_Addendum_2026-11-05.md)은
기계 판독 표의 `policy_overlays`에서 POLICY-AUTH-01~14 파생 검증으로 추적한다.
사용자가 원문 AC ID를 부여한 결정이 아니므로 기존 216개 원문 인벤토리를 늘리거나
기존 증거·상태를 덮어쓰지 않는다. 전체 권한 정책 인수는 NOT_RUN이며 기술 권한·OS 강제·
Host 관리자 위임·Builder 역할·사용자 전용 결정을 모두 확인해야 한다.

## 상태와 증거

초기 `NOT_RUN`은 **해당 현행 AC 전체를 현재 소스에 연결해 인수 판정하지 않았음**을
뜻한다. 기존 모듈/실제 AI/앱 시험이 한 번도 없었다는 뜻이 아니다.
해당 AC 전체 범위를 충족하는 증거를 연결하기 전에는 과거 시험이나 일부 검사만으로
PASS로 바꾸지 않는다. 현재 표의 전체 AC 합격 선언은 0개다.

담당 CTO·정확한 대상 Revision·실제 시험 이름·관측 결과·범위·제한을 확인해
각 행을 갱신한다. 부분 증거는 부분이라고 설명하고, UNKNOWN/BLOCKED/FAIL을
누락하거나 문서 수·커밋 수·계획 접수로 대체하지 않는다.

`attachment:` 원문은 사용자가 제공한 CSAS v0.8이다. 첨부 자체가 저장소에
포함됐다는 뜻이 아니다. 일반 인수 기준의 해당 원문 문장과 파일 해시를 표에 남겼으며
비공개 Core 코드·인증정보·사용자 실행 기록을 복사하지 않았다.
